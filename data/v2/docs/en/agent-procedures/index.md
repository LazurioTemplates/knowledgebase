This section is for the Organization's agents and for the people who give
them work. Every procedure says when to use it, what the agent works with,
which steps it takes, what it must not do on its own and how it checks the
result.

## What belongs here

- Repeated work an agent does: overviews, document drafts, data checks,
  preparing material.
- Boundaries: what the agent prepares and what a person must confirm.
  Sending a message, accepting a change, a payment or a deletion always waits
  for a person's instruction.

A procedure for agents is the Organization's knowledge that people read too.
When a procedure has settled and the agent should find it by itself, the
Organization can write a skill from it and link to the page from the skill.
